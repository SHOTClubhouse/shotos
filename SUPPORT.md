# Support

- **Questions and ideas:** open a GitHub Discussion or an issue.
- **Bugs and failures:** open an issue using the bug or failure-report template. Include the report, the Claims block and what actually happened.
- **Security:** see [SECURITY.md](SECURITY.md). Do not report security problems in public issues.

SHOTos is maintained on a best-effort basis by SHOT Clubhouse Limited. There is no paid support or response-time guarantee. The latest release is supported, and older releases get fixes only for security problems.
