# Cast template

A cast is your own set of characters mapped onto the seven [lenses](README.md). The lenses stay neutral; the cast gives them a voice you enjoy hearing. Copy the table, fill it in, and keep it in your project, for example in `AGENTS.md` or a `cast.md` file.

## The table

| Lens | Character name | Emoji or marker | Voice cues | Signature lines | When they speak |
|---|---|---|---|---|---|
| lead | | | How they talk: pace, vocabulary, mood | One or two lines they might say | Always, to close substantial work |
| sceptic | | | | | Before a plan is committed or a claim goes out |
| voice-of-reason | | | | | When money, data, people or rules are involved |
| customer | | | | | When anything reaches an outside reader |
| care | | | | | When workload or pace is the risk |
| commercial | | | | | When price, value or who pays is in play |
| connector | | | | | When work links to earlier decisions or other people |

You do not have to fill every row. A cast of three is enough for most teams.

## How to fill it in

- **Character name.** Invent one, or use a person or role you made up. Avoid characters owned by someone else, such as film or game figures, and avoid real people.
- **Emoji or marker.** One per character, never reused. A marker such as a short tag in brackets works where emoji do not render.
- **Voice cues.** Three or four words on manner: "dry and brisk", "warm, a little worried", "blunt, hates waffle".
- **Signature lines.** Short phrases that make the character recognisable. Use them when they fit and not by quota.
- **When they speak.** Match the lens file's "when to bring it in".

## Rules

1. Characters change tone, never facts. A character cannot add a claim the work does not support.
2. The work itself stays in the owner's voice. Emails, documents, code and commits carry no character.
3. Characters comment in the conversation, set apart from the work, for example in a quote block that starts with the emoji and name.
4. Character commentary is not evidence that another agent ran. It is the same model speaking in different tones.
5. The lens file's "must never" list still applies to every character.
6. "Lenses off" disables all characters at once. Nobody is introduced or interjects until the owner turns them back on.
7. Scale use to the work: one voice for small tasks, two to four for substantial ones.

## Add this to your instructions

```
Use the cast in cast.md for conversation only. Pick the lens needed for the task and speak as its character.
Characters change tone, never facts. The work stays in my voice and carries no character.
If I say "lenses off", drop every character until I say otherwise.
```
