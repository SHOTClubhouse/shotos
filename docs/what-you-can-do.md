# What you can do with SHOTos

Pick the job, install the pack, and ask in plain words. Every skill below drafts first and stops for your yes before anything is sent, posted, published, bought or deleted. The prompts are examples: change the details to fit your own work.

## Make things

| I want to | Skill | Try asking |
|---|---|---|
| Write a proposal for a client | [contextual-proposal](../packs/win-the-work/skills/contextual-proposal/README.md) | "Write a proposal for Northgate Cycles from our approved facts and my meeting notes. Price their 64 bikes and check every claim." |
| Research a decision from source material | [research-and-assemble](../skills/research-and-assemble/README.md) | Give me the three facts that could change this decision and show the source for each. |
| Build a campaign website preview | [campaign-website](../packs/content/skills/campaign-website/README.md) | Build a preview with one primary action and show me what works on a phone. |
| Design campaign graphics | [Campaign graphics](../packs/media/skills/image-create/campaign-graphics.md) | Make an editable hero and square tile from this approved copy, and check both crops. |
| Make a slide deck | [slide-deck](../packs/content/skills/slide-deck/README.md) | "Make a ten-slide board update on the repairs backlog. Show me the storyline first, then render and check every slide." |
| Create an image | [image-create](../packs/media/skills/image-create/README.md) | "Create a hero image for our blog on tenancy deposits. Flat illustration, no people, 16:9. Look at it properly and give me alt text." |
| Make a short video | [video-storyboard](../packs/media/skills/video-storyboard/README.md) | "Storyboard a 45-second video on how our servicing plan works, then build the shot list." |
| Record a voiceover or spoken message | [voiceover](../packs/media/skills/voiceover/README.md) | "Make a 30-second voiceover from this script in a friendly British voice. Check every price and name is said correctly." |
| Make a product demo video | [product-demo-video](../packs/content/skills/product-demo-video/README.md) | "Record a two-minute demo of booking a repair in our app, on test data, with subtitles." |
| Write a paper, report or blog post | [written-content](../packs/content/skills/written-content/README.md) | "Write a 900-word blog post on why repairs take longer in winter, with every fact sourced." |
| Translate a letter, transcript or captions | [translate](../packs/writing/skills/translate/README.md) | "Translate this camp letter into Polish and Portuguese. Check every date and price." |
| Write an explainer | [explainer](../packs/content/skills/explainer/README.md) | "Write an explainer for new landlords on how our deposit protection works." |
| Draft a press release | [press-release](../packs/content/skills/press-release/README.md) | "Draft a release about our pilot with the council. Be careful what we call it." |

Pilot three first." |

## Run a project through the six stages

| I want to | Skill | Try asking |
|---|---|---|
| Understand a problem before fixing it | [capture-the-problem](../skills/capture-the-problem/README.md) | "Customers keep ringing about allergens. Help me get clear on the real problem." |
| Agree what done looks like | [agree-acceptance](../skills/agree-acceptance/README.md) | "Before you start: set up acceptance for the new booking form." |
| Measure where we are today | [baseline](../skills/baseline/README.md) | "Record our baseline for supplier invoice queries from this export." |
| Prove whether it worked | [evidence-pack](../skills/evidence-pack/README.md) | "Compare this quarter with the baseline and draft the evidence pack." |
| Test a bet in a bounded pilot | [hypothesis card](../skills/hypothesis-card/README.md), [pilot before scale](../skills/pilot-before-scale/README.md) | "Set our success threshold, guard checks and stop conditions before the pilot." |
| Hand work over | [evidence-handoff](../skills/evidence-handoff/README.md), [runbook](../skills/runbook/README.md) | "Write the handoff and a runbook so the team can run this without me." |
| Prove the team can run it | [enablement plan](../skills/enablement-plan/README.md) | "Plan an independent cycle and record who will accept it." |
| Take the method to a second team | [rollout plan](../skills/rollout-plan/README.md) | "Check the handoff and sponsor approval, then plan one wave with its own baseline." |
| Check an agent's work | [cross-agent-review](../skills/cross-agent-review/README.md) | "Have a second model review this proposal against the acceptance card." |

First time? Ask the agent to run [connect-tools](../packs/setup/skills/connect-tools/README.md): it checks which of these your set-up can do today.

Can't see your job here? Ask for the closest skill, or start with [capture-the-problem](../skills/capture-the-problem/README.md) and [agree-acceptance](../skills/agree-acceptance/README.md): they work for any piece of work.
