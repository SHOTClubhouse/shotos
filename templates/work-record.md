# Work record

Reuse the issue, deal, document or task that already owns the work. Use this template in `.work/<task>/work-record.md` when there is no existing record. Keep restricted evidence in its approved home and link to it from here when access permits.

| Field | Record |
| --- | --- |
| Request and decision | What the reader or operator needs to do with the result |
| Context | Audience, organisation, current state, relevant prior decisions and constraints |
| Evidence | Source, date, scope and whether observed, reported, inferred or unknown |
| Authority | Named owner, permitted actions and any decision still needed |
| Acceptance | Observable checks and a case that should fail |
| Route | Stage, skills opened, role responsible and any review lens used |
| Result | Canonical location, version and status |
| Verification | What was opened or run, result, and open checks |
| Next action | Named owner, action, review date and acceptance or receipt when available |

Link to the original request and keep this record current across sessions. For an initiative crossing stages, add the [programme record](programme.md) and link to this task from the relevant stage.
