# Brief

Fill this in once, then save it as `BRIEF.md` in your project folder or add it to your chat project. Where the SHOTos working agreement is loaded, every skill reads the brief before asking you anything, so you do not explain your work twice. In a single chat without the agreement, attach the brief and ask the agent to read it first.

Rough answers are fine. Leave a line blank if you do not know. The agent asks only for what changes its result, and writes "not known" or "not measured" where a gap remains.

Keep it short and current. Put private material (personal details, health, passwords, customer records) in its own system, not here. You may name where it lives; the agent opens it only when the task has approval for that data.
