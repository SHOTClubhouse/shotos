# Northbank Community Football

A fictional three-page website and open-day campaign showing how SHOTos goes from brief to a verified public release. All club details are invented. The pitch illustration is original SVG and the pages use local assets.

[Open the live example](https://shotclubhouse.github.io/shotos/) · [Open the campaign](https://shotclubhouse.github.io/shotos/open-day.html)

1. Read the [site brief example](../../packs/content/examples/build-small-website/input.md).
2. Open [Home](site/index.html), [Sessions](site/sessions.html) and [Open day](site/open-day.html). The main campaign action opens an on-page itinerary.
3. Compare the public [deployment marker](https://shotclubhouse.github.io/shotos/release.json) with the GitHub Pages run. Open the public pages and follow the paths in the [site output example](../../packs/content/examples/build-small-website/output.md).
4. Record the actual result using [Verify a Live Release](../../packs/setup/skills/verify-live-release/README.md).

The [Build a Small Website](../../packs/content/skills/build-small-website/README.md) skill covers the site. [Campaign Website](../../packs/content/skills/campaign-website/README.md) covers the event page.

Use the [two-round campaign review](campaign-review.md) to try the campaign brief, worked graphic, decision and operator handoff with fictional records.
