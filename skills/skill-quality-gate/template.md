## Pre-publication disclosure checklist (for Public-ready or any release outside the organisation)
- [ ] No real names, customers, suppliers or private data in the skill, examples or evals
- [ ] No secrets, tokens, internal paths or addresses
- [ ] Every example is labelled as invented
- [ ] Claims about results say whether they were run, by whom and how many times
- [ ] Licence and credits are present for any public framework named
- [ ] Anything the skill can send, post, buy or delete drafts by default
- [ ] Known limits are written in the README
- [ ] A named person has cleared publication
