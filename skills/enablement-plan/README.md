# enablement-plan

**Plan how a team becomes able to run the result without the builders, and prove it with one full cycle.**

The agent builds a capability matrix of person by skill with four levels, finds single points of failure, schedules pairing from watch to do to alone, sets up train-the-trainer, writes the exit criterion first and plans a fault drill. The exit is a full cycle run by the team with the builders only observing.

It supports the Hand over step. It serves rule 2, Agree acceptance first, because the exit is agreed before training, and rule 3, Read back the real result, because levels come from observation.

## The problem it solves

At a fictional firm, Northgate Cycles, a contractor built an automated weekly workshop schedule. It works while she is around. When she moves to another project, the staff can run the routine but nobody can tell a bad schedule from a good one, and nobody knows how to fix a missing mechanic's holiday date. A month later the owner is back to doing it by hand.

The plan shows that only one person can check results, schedules three short pairing rounds on real weeks, and ends with a cycle the staff run alone, with a planted holiday error to find.

## When to use it, and when not to

Use it before the builders step back, and when a result still depends on them. Skip it for a one-off or when a vendor runs the service permanently.

## Who it is for

- **Business unit leader:** a way to know the team is ready, not just trained.
- **Small team lead:** short pairing rounds on real work.
- **Enablement coach:** the matrix and the exit test.
- **Engineering or practice lead:** train-the-trainer so knowledge spreads.

## How to use it

Ask:

> Draft an enablement plan for the weekly workshop schedule. Receiving team: Ines, Tariq and Bo. Builder: Hana, leaving on 28 November. Make the exit a full cycle run without her.

Correct the levels from your own observation, then agree the exit criterion with the sponsor before the first session.

## Needs

Nothing beyond the agent. Observation of people at work is done by a person.

**Evidence:** Tested in a paired run on 3 November 2026, one run per case, graded by meaning. Cases passed with SHOTos: Haiku 2 of 2, Sonnet 2 of 2, Opus 2 of 2. Without: Haiku 2 of 2, Sonnet 2 of 2, Opus 2 of 2. See [evidence](../../docs/evidence.md) for how to read this.

## Tips and common mistakes

- Score from watching someone do the task.
- Agree the exit before training begins.
- Do not count attendance as ability.
- Plant a safe fault; real faults come at bad times.

## Limits

- It cannot make people available. Time must be freed by the sponsor.
- A pass on one cycle shows readiness, not long-term durability. Revisit after a quarter.
