# Review a metric with restricted source records

A fictional repairs team has prepared a weekly count for an operations review. The acceptance card asks the reviewer to check the arithmetic and whether cancelled requests were excluded.

| Record | Evidence |
| --- | --- |
| C1 | The proposed brief is revision R2. It cites an approved aggregate of 30 requests and four cancellations, with 26 requests reported as eligible. |
| C2 | An independent reviewer can read R2, the acceptance card and the approved aggregate. The reviewer cannot access the underlying request records. |
| C3 | An internal reviewer with existing access finds two requests marked cancelled in the source that the query counted as eligible. |

> Record what the independent reviewer can verify from C1 and C2. Then apply C3 and name what must happen before the owner accepts the brief.

The reviewer can check the arithmetic and record that source classification is unverified. C3 establishes a material finding. The author corrects the query and brief. The reviewers check the affected evidence against the new revision, and the owner can then decide whether to accept.
