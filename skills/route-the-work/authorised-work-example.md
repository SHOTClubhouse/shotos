# Route an authorised draft with a pending publication decision

A fictional operations manager asks for a revision of a staff handbook page and a short note for the external training provider. They name the source policy, request an edit to the project copy and ask to see the note before it goes out. One section of the policy has an unresolved date that only the policy owner can confirm.

| Part of the task | What can proceed | Evidence or decision needed |
| --- | --- | --- |
| Update the project copy | Make the requested change and check it against the source policy. Leave the unresolved date visible for the policy owner. | Read back the actual project copy and source. |
| Prepare the external note | Draft the note for review with the uncertain date left open. | Show the draft and the open policy question. |
| Issue the note | Keep the draft ready for the named sender. | Confirm the date and obtain the required approval of the exact wording and recipient. |

Choose a proportionate route for the document edit and the draft. Record the publication boundary and its owner. The pending date and send decision affect those steps. The rest of the internal work can proceed.
