# Worked output

**Draft for buyer review.** Request a six-room booking tool and a representative data export. Ask each supplier for a staged implementation plan, support hours and a separate price for setup and recurring use.

**Mandatory gate:** The evaluator can open and read the sample export. A failed gate stays a failed gate at every score.

| Scored criterion | Weight | What to compare |
| --- | ---: | --- |
| Workflow fit | 45% | How the supplied demonstration handles a change and cancellation. |
| Implementation and support | 30% | Named responsibilities, timeline assumptions and escalation examples. |
| Total cost | 25% | Comparable setup and recurring costs, with exclusions stated. |

Publish the same clarifications to invited suppliers through the approved channel if the buyer authorises issue. Date, authority and issue status are open.
