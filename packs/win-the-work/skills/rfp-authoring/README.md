# RFP authoring

Use this to ask suppliers for comparable evidence, offers and pricing. It gives the buying team an invitation draft and a shared way to assess the replies.

**Stage:** Hypothesise. **Rules:** Boundaries, agreed acceptance and claims.

**Needs:** A buying owner, scope, constraints and a qualified review of the proposed route. The team handles issue and award.


**Evidence:** Cases written, not yet run.
