# Bid response

Use this when a buyer has already issued a tender, bid pack or RFP. The bid lead gets an evidence-linked recommendation, requirements matrix and draft response. Use the buyer's official criteria and latest instructions.

**Stage:** Operate. **Rules:** Boundaries, agreed acceptance, read-back and claims.

**Needs:** Tender pack, amendments, approved supplier evidence and a human submission owner. Contract or compliance findings need the team's qualified reviewer.


**Evidence:** Cases written, not yet run.
