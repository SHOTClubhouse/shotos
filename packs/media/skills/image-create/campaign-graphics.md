# Design graphics for a campaign

Read this when producing a website hero, event tile, social graphic or display graphic from the same campaign. Use the actual copy, audience and asset rights, and set acceptance before making variants.

| Capture | What the next person needs |
| --- | --- |
| Brief | Audience, one job, destination, primary message, action and copy approver |
| Design | Editable master, approved logo and image references, type and colour roles, safe areas for each crop |
| Proof | Final-size previews, the copy and crop checked at each size, contrast, alt text and any usage limits |
| Handoff | Approved revision, exports, editable source, rights record and the person who can publish |

Use a generated illustration when it supports the message. Keep headlines and factual labels editable in the layout. Preserve source and credit for borrowed assets. If rights or copy approval are missing, use a clearly labelled placeholder in the preview.

**Fictional example.** A repair workshop needs a website hero and a square social tile. The approved subject is a maintenance morning. A wheel diagram supports it, with the title typeset separately. Inspect the hero at its narrow crop and the tile at actual display size. The design fails if either crop removes the action or if an unapproved date appears. Carry one editable master and two labelled exports into the campaign record.
