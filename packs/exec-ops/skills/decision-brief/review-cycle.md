# Executive Decision Review

Use this for a recurring leadership choice that needs a recommendation, a recorded decision and someone to run the next review. Start with one choice from the weekly briefing or operating meeting. Give the decision maker a one-page brief and link to the evidence in the owning record.

## Prepare the brief

1. Open the owning record and the last decision. Set the review window, decision question, named decider and when it is needed. If authority or timing is unclear, mark it open.
2. Gather what changed, with dated source links. Label observed facts, reported claims, assumptions and gaps. Carry forward only unresolved work that affects this choice.
3. Use `decision-brief` for options, trade-offs, a recommendation and the evidence that would change it. Include hold when a missing prerequisite could change the choice.
4. For a proposal, open the exact buyer draft and its private working sheet. Check the approved offer, draft revision, authority to send and dispatch evidence separately. Identify who can approve pricing or entitlements from the authority record. Leave proposed terms in the private working sheet while that approval is missing. Use `contextual-proposal` if the buyer draft needs work. Link to restricted terms rather than copying them into the briefing.

## Record the decision and hand over

5. Use `decision-record` once the named decider confirms the choice. Record the date, rationale, approval scope and source. While waiting, mark the decision pending. Keep the recommendation, decision and any authority to act separate.
6. Use `evidence-handoff` with the decision or pending question, source links, permitted access, one next action, what would stop it and a date or explicit date gap. Mark the handoff Prepared until you can show the offer was sent. Record receiver acceptance separately, including scope, access and first action. Save both outputs against the same owning record.
7. Have the next operator use that record to find fresh evidence, draft the next brief, obtain and record the decision, and hand off the next action. The original author observes. Record the receiving lead, cycle date, outputs, interruptions and acceptance evidence. If the operator needs missing context or the original author takes over any step, record the intervention and repeat the cycle after fixing the handoff. The authorised decider may still make the decision. That is a role in the workflow, separate from operating the cycle.

**Pass the independent-cycle check** when an observer can trace all four steps and a human accepts the result, with no intervention from the original operator. A dated decision to hold counts as a decision. If the decider has yet to respond, record partial completion and leave the full-cycle verdict open.

## Track the review

Use one row per cycle in the owning record. Use the accepted-work ledger if the team already tracks work there.

| Cycle and source cutoff | Request to accepted brief | Review and rework minutes | Material corrections | Handoff pickup time | Operator and assistance | Decision and acceptance evidence |
| --- | --- | --- | --- | --- | --- | --- |
| Baseline from comparable work, or mark unmeasured | | | | | | |
| Next cycle | | | | | | |

Keep missing measures blank or mark them unmeasured. Track attempts and model spend when available. A faster draft is only one part of the cycle. Compare the time and corrections needed to get to a human-accepted brief, and check whether the next operator could run it. Record a sponsor decision to continue, revise or stop before expanding to another team.
