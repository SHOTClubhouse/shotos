# Build a Small Website

Use this Operate skill when a founder, club lead, service owner or communications team needs several pages with a shared identity. The page map gives the builder and reviewer the same outcomes to check, from finding information to completing an authorised action.

1. Fill in the [site brief](template.md) with the owner, up to three visitor journeys, approved claims and any integrations.
2. Build the preview and follow each route, including direct page links, keyboard use and a narrow screen. Record a visible result or destination for each journey.
3. Save the source revision and preview with the owner. Once the owner publishes, use [Verify a Live Release](../../../setup/skills/verify-live-release/README.md) to check those journeys in their public home.

Use [Campaign Website](../campaign-website/README.md) for a single campaign action. For a site with accounts, payments or sensitive data, bring the responsible owner into the design and testing of that integration.

## Try it

Open the bundled [input](../../examples/build-small-website/input.md) first and keep the [worked output](../../examples/build-small-website/output.md) for review. [Northbank Community Football](../../../../examples/northbank-club/README.md) is the same fictional three-page site, with the source and public demo linked.

**Needs:** A site builder or repository you can edit, approved content and a way to exercise the preview. Publication uses the project's own hosting and permissions.

**Evidence:** Example only for the build instructions. The [Northbank read-back](../../../../examples/northbank-club/README.md#public-read-back) records checks on the published fictional site.
