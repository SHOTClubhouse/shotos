# Campaign website

Build a focused campaign page with one primary action. The page owner gets an editable preview, source and asset checks, and clear evidence of what the visitor can do.

**Stage:** Operate. **Rules:** Boundaries, agreed acceptance, read-back and claims.

**Needs:** Approved copy and assets, a site builder or local project, and a browser for verification. A live destination or data collection needs the appropriate owner.


Download [preview.html](preview.html) and open it in your browser to try the fictional example. Use the primary link with a mouse or keyboard to open the session outline.

**Evidence:** Cases written, not yet run.
