# Brief a visual that explains a decision

In this fictional example, an operations manager wants a one-page explainer on how a new colleague starts handling invoice queries. The repeated misunderstanding is that a correct first draft automatically transfers ownership.

| Brief item | Direction |
| --- | --- |
| Reader and job | A new colleague should be able to say whether they own the next cycle and where to check. |
| Moment to show | Show the same query record before review, after the draft is accepted, and after the receiving lead accepts the next cycle. |
| What changes | The first review checks the draft. The second record names the receiver and confirms the first action. Use visible labels for both events. |
| What stays visible | If the receiving lead has yet to accept, show the next action with the current owner. The approved draft remains available. |
| Text alternative | “The draft review and ownership acceptance are two separate steps.” Put the sequence and the owner of each step in text beside the visual. |
| Review check | A colleague who saw only the visual can point to the record that changes ownership. A colleague who reads only the text can do the same. |

Choose a diagram or an annotated comparison that keeps the two events distinct. Check labels, reading order and legibility at the final size. Base the final visual on the actual handoff record or keep it labelled as illustrative.
