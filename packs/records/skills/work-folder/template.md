# Task folder template

Create this layout for each task.

```
.work/YYYY-MM-DD_subject/
  acceptance.md    owner, outcome, checks, a failing case, boundaries
  notes.md         dated lines: decisions, questions, state
  scratch/         throwaway; safe to delete
  outputs/         files meant to leave the folder
```

## notes.md

```
# <subject>
Owner: <name>
Opened: <date>

- <date> <decision, question or state, in one line>
```

## Close-out list

| File | Group (move, archive, delete) | Destination | Owner's yes |
|---|---|---|---|
| | | | |

Closed: <date>. Accepted by: <name>. Outputs went to: <place>.
